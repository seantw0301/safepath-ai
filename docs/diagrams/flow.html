SafePath AI 流程圖 How it works

從拍攝到驗證：看見擋路的東西 → 改善它 → 有證據才由紅轉綠

1
手機拍攝

繞家走一圈拍照或錄影，A4 紙貼門框當比例尺

Film the home; A4 sheet = scale

2
SAM 3.1 偵測

用文字找出門檻、電線、地毯、雜物，影片中持續追蹤

Text-prompted masks + video tracking

Meta SAM 3.1
3
量測＋規則判定

量門寬、門檻高，檢查行走動線；紅黃綠由規則表決定

Measure; verdicts from a rule table

4
Muse Spark 複核

Agent 對照照片逐項檢查；有疑慮交給人工確認

Case agent checks each finding

Meta Muse Spark
產出文件
5
工單＋補助草稿

清除清單、施工工單、長照 2.0 居家無障礙補助申請草稿（PDF）

Work orders + LTC 2.0 subsidy draft

6
施工・清除

家人清走雜物，師傅依工單施工

Clear clutter, repair

7
同路線重拍

施工後沿同一路線再拍一次

Re-film the same route

8
驗證：紅 → 綠

Verify Agent 比對前後照片，有證據才轉綠

Before vs after; green only with evidence

Meta Muse Spark

紅黃綠判定來自規則表，不由模型決定；邊界值一律交人工量測。 · Verdicts come from rules, not the model.
